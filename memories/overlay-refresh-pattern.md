# Overlay refresh pattern

- Designer extensions should pass existing SVG nodes back into `_drawLine`, `_drawCircle`, and `_drawPath`, and gate refresh work with `_valuesHaveChanges`.
- Share coordinate caches across a synchronous selection/overlay refresh batch instead of clearing them for each extension type. Clear them at batch boundaries, on content notifications, and around temporary source-SVG marker geometry. Keep the shared-read and subsequent-layout-change regression in `CanvasRootMargin.browser.mjs`.
- Rebuild overlays only when their structure changes, such as segment count/type or control-point presence. Updating existing nodes preserves pointer capture and avoids stale handles.
- SVG outline conversion reads the element's reference box and overlay transform once per path, then maps its points with that snapshot. Recompute on each conversion so edits, pan, zoom and transforms remain current. `SvgMarkerHover.browser.mjs` covers bounded geometry reads for long paths and refresh after a transform edit.
- Position guides project their starts, ends and label centers as three quads, retaining homogeneous coordinates for perspective while sharing each coordinate conversion across four points. Keep rotation/skew, docking and anchor-editing checks in `PositionExtension.test.ts`.
- Miniature services may implement `shouldRefresh(canvas, changes)` to suppress irrelevant content redraws. Missing hooks preserve unconditional redraw behavior; initial attachment and viewport-rectangle updates do not depend on this hook.
- Filtered `reapplyAllAppliedExtentions` visits the supplied DesignItems directly instead of traversing the full document. It must still reevaluate previously rejected providers on those items; unfiltered calls retain full-document discovery. Check `ExtensionManagerReapply.test.ts`.
- Quads use the canvas host's border-box origin. If `:host` (or patched `:root`) moves that host with margins, `fillCalculationrects()` aligns the separate overlay layer and normalized pointer/element coordinates to that origin. The translation uses screen pixels so it remains correct under zoom and pan. Both native Firefox and Chromium's polyfill require this designer adjustment; do not compensate inside getBoxQuads.
- `npm run test:canvas-root-margin` checks live stylesheet edits, positive/negative margins, padding, pan, and 50/100/200% zoom in Chromium and Firefox. Install its browsers with `npx playwright install chromium firefox`.
